# 人員工作分配與 Web GIS 導航系統 — 系統規劃與開發規格書

**文件版本**：v1.0（需求定案初版）  
**系統定位**：無伺服器架構（GitHub Pages + Google Apps Script）之團隊人力調度、月/日曆排程與空間定位導航系統

---

## 1. 系統架構與技術選型 (System Architecture)

本系統採用前後端分離的 **Serverless（無伺服器）** 架構，免除租用主機與資料庫的維護成本，同時兼顧資料安全性與高互動性：

* **前端展示與互動層（託管於 GitHub Pages）**：
  * **核心技術**：HTML5, Tailwind CSS（響應式美學設計）, Vanilla JavaScript (ES6+)。
  * **地圖與空間運算引擎**：Leaflet.js（輕量高效能 Web GIS 框架） + Proj4js（TWD97 座標精準轉換引擎）。
  * **日曆與拖曳引擎**：自研輕量雙模式日曆組件（支援「月曆 / 日曆」無縫切換，以及桌面端 Drag & Drop 與觸控端手勢滑動）。
* **後端 API 與安全驗證層（Google Apps Script, GAS）**：
  * 發布為 Web App（`執行身分：我`、`存取權限：所有人`），作為前端與 Google Sheets 之間的唯一資料通道。
* **雲端資料庫層（Google Sheets）**：
  * 作為結構化關聯資料表，方便管理者在緊急狀況下也能直接從 Google 試算表檢視或備份原始資料。

```text
[ 使用者 / 管理者瀏覽器 (GitHub Pages) ]
       │
       ├── 1. 輸入密碼驗證 (HTTPS POST) ──────────► [ Google Apps Script (GAS) ]
       │                                                  │ (讀取 Script Properties 比對密碼)
       │◄── 2. 回傳 Role (viewer/admin) + Token ──────────┤ (寫入 CacheService 暫存憑證)
       │                                                  │
       ├── 3. 攜帶 Token 請求/寫入資料 ──────────────────►├──► [ Google Sheets 資料庫 ]
       │                                                  │      ├─ Personnel (人員表)
       │◄── 4. 回傳 JSON 資料 (樂觀更新 + 背景同步) ───────┘      ├─ Locations (地點表)
       │                                                         └─ Schedules (派工表)
       └── 5. 外部喚起 ──► [ Google Maps 導航模式 ] / [ 國土測繪中心 WMTS 圖磚 ]
```

## 2. 資安驗證與權限控管設計 (Security & Auth)

為解決靜態網頁（GitHub Pages）原始碼公開的資安風險，系統採取以下防護機制：

1. **密碼零暴露原則**：前端程式碼中**絕不儲存**任何密碼字串或雜湊值。
2. **GAS 伺服器端驗證**：
   * 管理者於 GAS 後台的「專案設定 > 指令碼屬性（Script Properties）」中設定兩組環境變數：`USER_PASSWORD`（前台檢視密碼）與 `ADMIN_PASSWORD`（後台管理密碼）。
   * 登入畫面僅需一個「通行密碼」輸入框，無需帳號 ID。前端送出密碼後，由 GAS 判斷屬於哪一種身分。
3. **動態 Session Token 機制**：
   * 驗證成功後，GAS 產生一組隨機 UUID Token，存入 `CacheService`（預設有效期限 12 小時），並回傳前端 `{ role: 'viewer' | 'admin', token: '...' }`。
   * 前端將 Token 暫存於 `sessionStorage`（關閉分頁即自動登出，亦可手動點擊登出）。
   * **API 權限守門員**：所有讀取資料 API 皆須驗證 Token 有效性；所有新增、修改、刪除、派工寫入 API 皆強制驗證該 Token 對應的身分必須為 `admin`，否則直接拒絕存取。
4. **團隊資訊透明原則**：因屬同一工作團隊，不論以 `viewer` 或 `admin` 身分登入，皆可完整檢視所有人員的聯絡電話、車輛車號與備註，以利外業當天即時聯繫調度。

## 3. Google Sheets 資料庫結構設計 (Database Schema)

Google 試算表內建立三個核心工作表（Sheets），採用關聯式設計以支援「同日多地點」與「同地點多人出席」：

### 3.1 `Personnel`（人員資料表）
| 欄位名稱 | 類型 | 說明 | 範例 |
| :--- | :--- | :--- | :--- |
| `id` | String (PK) | 系統自動產生唯一碼 | `EMP_1700123456` |
| `unit` | String | 所屬單位（用於前台抽屜分組） | `第一工務段` |
| `name` | String | 人員姓名 | `王大明` |
| `phone` | String | 聯絡電話（手機版支援點擊直接撥號） | `0912-345-678` |
| `plate` | String | 車輛車號 | `ABC-1234` |
| `note` | String | 備註事項（如特殊證照、裝備等） | `具備無人機操作證` |

### 3.2 `Locations`（工作地點資料表）
| 欄位名稱 | 類型 | 說明 | 範例 |
| :--- | :--- | :--- | :--- |
| `id` | String (PK) | 系統自動產生唯一碼 | `LOC_1700123999` |
| `unit` | String | 主責單位 / 轄區（用於地點抽屜分組） | `北區轄區` |
| `name` | String | 工作地點名稱 | `大安溪橋墩檢測點` |
| `twd97_x` | Number | TWD97 121分帶 X 座標（東距） | `231450.52` |
| `twd97_y` | Number | TWD97 121分帶 Y 座標（北距） | `2691230.88` |

### 3.3 `Schedules`（派工排程資料表）
| 欄位名稱 | 類型 | 說明 | 範例 |
| :--- | :--- | :--- | :--- |
| `id` | String (PK) | 派工紀錄唯一碼 | `SCH_1700124555` |
| `date` | String | 派工日期（ISO 格式 `YYYY-MM-DD`，整日為單位） | `2026-11-20` |
| `personnel_id` | String (FK) | 關聯 `Personnel.id` | `EMP_1700123456` |
| `location_id` | String (FK) | 關聯 `Locations.id` | `LOC_1700123999` |
| `updated_at` | Timestamp | 最後更新時間 | `2026-11-16 20:45:00` |

> **設計亮點**：將每筆「日期 + 人員 + 地點」存為獨立紀錄，可完美支援「同一地點同一天有多位人員出席」，也保留「同一人員同一天支援多個地點」的彈性。

## 4. Web GIS 空間資訊與導航規格

### 4.1 座標系統轉換（TWD97 121分帶 $\rightarrow$ WGS84）
* 系統僅處理台灣本島 **TWD97 TM2 121分帶（EPSG:3826）** 座標。
* 前端載入資料時，透過 `Proj4js` 內建標準參數即時運算轉換為地圖與 Google Maps 所需的 WGS84 經緯度（EPSG:4326）：
  * `EPSG:3826` 定義：`+proj=tmerc +lat_0=0 +lon_0=121 +k=0.9999 +x_0=250000 +y_0=0 +ellps=GRS80 +units=m +no_defs`
* **防呆檢核**：後台新增/編輯地點輸入 TWD97 X/Y 時，系統自動檢核數值合理範圍（X 介於 `140,000 ~ 360,000`，Y 介於 `2,400,000 ~ 2,800,000`），避免使用者將 X 與 Y 填反，並提供即時小地圖預覽圖釘位置。

### 4.2 四大切換式地圖底圖（WMTS 圖層）
地圖右上角配置「圖層切換控制面板」，提供使用者隨時切換以下四種底圖（預設為「臺灣通用電子地圖」）：
1. **臺灣通用電子地圖（國土測繪中心 NLSC）**：`https://wmts.nlsc.gov.tw/wmts/EMAP/default/GoogleMapsCompatible/{z}/{y}/{x}`
2. **正射影像圖 / 衛星航照（國土測繪中心 NLSC）**：`https://wmts.nlsc.gov.tw/wmts/PHOTO2/default/GoogleMapsCompatible/{z}/{y}/{x}`
3. **臺灣通用混和地圖 / 影像含路網地標（國土測繪中心 NLSC）**：`https://wmts.nlsc.gov.tw/wmts/PHOTO_MIX/default/GoogleMapsCompatible/{z}/{y}/{x}`
4. **OpenStreetMap 標準街道圖（OSM）**：`https://tile.openstreetmap.org/{z}/{x}/{y}.png`

### 4.3 Google Maps 一鍵導航規格
* 點擊左側地點清單中的任一工作地點，卡片平滑展開「**Google Maps 導航**」主按鈕。
* 點擊後直接透過標準 Google Maps Directions URL Scheme 開啟外部導航：
  * `https://www.google.com/maps/dir/?api=1&destination={lat},{lng}&travelmode=driving`
  * 在手機上將自動喚起 Google Maps App 並直接進入「起點（目前 GPS 位置）$\rightarrow$ 終點（工作地點）」的導航規劃畫面；不額外放置複製座標或檢視地標按鈕，保持介面極簡。

## 5. 前台「人員－日曆－地圖」三方連動邏輯

系統維護三個核心互動狀態：`selectedPersonId`（選中人員）、`selectedLocationId`（選中地點）、`activeDate`（鎖定日期，預設為**今日**）。

### 5.1 預設初始狀態（未點選任何人或地點時）
* **Web GIS 地圖**：顯示資料庫中**全部的工作地點圖釘**（標準深海藍圖釘），讓團隊掌握整體轄區分布。
* **日曆視圖**：預設為「月曆模式」（可一鍵切換為「日曆/單日詳細模式」），顯示每日已排定的出工摘要標籤（如地點名稱與人數）。
* **人員與地點抽屜**：可自由展開/收合各單位抽屜；地點清單上方提供「關鍵字即時搜尋框」。

### 5.2 四大雙向連動觸發規則
1. **點選「左側人員卡片」時**：
   * **人員清單**：該人員卡片加上高對比強調外框。
   * **日曆視圖**：日曆上凡是該員有被排定工作的日期，皆以強調色標示（並顯示當天去的地點）。
   * **Web GIS 地圖**：動態更新圖釘狀態——該人員被排定的工作地點圖釘轉換為**高對比強調色（琥珀橘）並放大跳動**，其餘無關地點圖釘則自動變為半透明淡化（若使用者同時點選了日曆上的某一天，則地圖進一步聚焦為「該員在該日」的工作地點）。
2. **點選「左側工作地點清單」時**：
   * **地點清單**：該地點卡片變換背景強調色，並展開「Google Maps 導航」按鈕。
   * **Web GIS 地圖**：地圖視角平滑移動並縮放（`flyTo`）至該地點位置，該圖釘轉為強調色並開啟名稱提示框（Tooltip）。
   * **日曆與人員聯動**：日曆標示該地點有排程的日期；同時依據當前日曆鎖定日期（`activeDate`，預設為今日），自動展開人員清單中對應的單位抽屜，將**當天要去該地點的全部人員**卡片換上明顯強調色。
3. **點選「地圖上的工作地點圖釘」時**：
   * **地點清單**：自動展開該地點所屬的「主責單位」抽屜，平滑捲動至該地點卡片並換上明顯強調色（同步展開導航按鈕）。
   * **人員清單（依日期聯動）**：查詢 `activeDate`（目前日曆所選日期，預設為今日）被指派前往該地點的**全部人員**，自動展開他們所屬的單位抽屜，並將這些出席人員的卡片換上明顯強調色（地圖上方同時顯示目前查詢的日期提示標籤，方便使用者切換日曆日期來查看不同天該地點的出席名單）。
4. **點選「日曆上的某個日期」時**：
   * 更新 `activeDate` 為該日期（並以明顯邊框標示該日為目前檢視日）。
   * **Web GIS 地圖**：即時更新為「該日有排定出工的全部地點」亮起強調色，其餘未出工地點淡化；若此時再點擊地圖圖釘，人員清單即顯示「這一天」要去該地點的所有人員。
5. **一鍵重置（清除選取）**：
   * 在左側面板頂部（手機版位於頁 1 頂部）設置明顯的「**清除選取 / 重置條件**」按鈕。點擊後清空 `selectedPersonId` 與 `selectedLocationId`、`activeDate` 回到今日，日曆與地圖瞬間恢復為顯示全部地點的乾淨預設畫面。

## 6. 後台管理與排班操作規格（Admin Mode）

登入時輸入管理者密碼後，系統頂部切換為「後台管理模式」指示列，解鎖以下功能：

### 6.1 基礎資料 CRUD 管理
* **人員管理**：提供「+ 新增人員」按鈕，以及每張人員卡片上的「編輯 / 刪除」圖示。可維護單位、姓名、電話、車輛車號、備註（輸入既有的單位名稱時提供下拉自動帶入，避免同單位名稱打錯字導致抽屜分裂）。
* **工作地點管理**：提供「+ 新增工作地點」按鈕，以及每個地點卡片上的「編輯 / 刪除」圖示。可維護地點名稱、主責單位、TWD97 121 X 與 Y 座標。

### 6.2 排班派工流程（方案 B：拖曳人員 + 彈出選單）
* **桌面版拖曳派工**：
  1. 管理者直接從左上角單位抽屜中，按住某位「人員卡片」拖曳至中間日曆的「目標日期格子」放開。
  2. 系統立即彈出輕量級《**派工地點設定視窗**》（顯示：人員姓名、派工日期、該員當日已排定地點）。
  3. 管理者從分類清單或搜尋框中勾選該人員當天要前往的**工作地點**（支援單選或多選），點擊「確認派工」即完成（整日派工）。
* **觸控裝置 / 批次派工輔助（雙軌並進）**：
  * 考量手機與平板觸控操作，日曆每個日期格子右上角皆設有「**`+` 派工**」按鈕。點擊後可開啟《日期派工管理視窗》，讓管理者先選地點、再一次勾選多位出席人員，或直接移除/修改該日既有的排班紀錄。
* **流暢雲端同步機制（Optimistic UI）**：
  * 管理者每次確認派工或修改資料後，前端畫面**0 延遲即時更新**，同時將變更任務排入背景非同步佇列（Queue）送往 GAS 寫入 Google Sheets；畫面頂部顯示狀態膠囊（「☁️ 雲端同步中...」$\rightarrow$「✅ 已儲存至雲端」），確保連續排班操作行雲流水不卡頓。

## 7. UI/UX 美學規劃與多裝置響應式佈局

### 7.1 色彩系統與視覺層級（Color System）
* **介面基底色**：現代工程灰白（Cool Slate `#F8FAFC` 背景 + 純白 `#FFFFFF` 卡片 + `#E2E8F0` 細邊框），長時間檢視不刺眼。
* **系統品牌主色**：深海藍（Deep Ocean Blue `#0F4C81`），傳達專業、精準與空間工程信任感。
* **單位識別色標籤（Unit Badges）**：系統依據單位名稱自動分配柔和莫蘭迪色系膠囊標籤（如霧霾藍、鼠尾草綠、暖沙棕、薰衣草紫），讓同單位人員與同轄區地點一眼可辨。
* **聚焦強調色（Focus Highlight）**：當觸發聯動查詢時，受關注的人員卡片、地點卡片、日曆日期與地圖圖釘統一使用高對比**琥珀橘（`#F59E0B`）**或**翡翠綠（`#10B981`）**高亮呈現，非相關項目自動降低對比度，形成清晰的視覺焦點。

### 7.2 電腦版佈局（Desktop $\ge 1024\text{px}$）：三欄式全螢幕工作台
採用 `100vh` 無捲動外框（各區塊內部獨立捲動），資訊一覽無遺：
* **頂部導航列（Header, 高度 56px）**：系統名稱、今日日期與當前鎖定日期顯示、管理模式狀態 badge、登出按鈕。
* **左欄（寬度 300px ~ 320px，上下 50% / 50% 分割）**：
  * **上半部（人員抽屜區）**：依「單位名稱」建立可折疊手風琴抽屜，展開顯示人員卡片（姓名、車號、電話、備註圖示）。頂部附有「清除選取」重置按鈕。
  * **下半部（工作地點抽屜區）**：頂部配置「工作地點搜尋框」，下方依「主責單位」建立可折疊抽屜，點擊地點可展開「Google Maps 導航」按鈕。
* **中欄（彈性寬度 `flex-1`）**：
  * 頂部工具列提供「月曆 / 日曆」視圖切換器、上/下月（日）切換鈕與「回到今天」按鈕。
  * 主體為高可讀性的 Google 行事曆風格排程表。
* **右欄（寬度 38% ~ 42%）**：
  * 滿版互動式 Web GIS 地圖，右上角配置 4 種底圖切換器，左上角顯示當前地圖篩選狀態提示條（如：「目前顯示：2026/11/20 出工地點」或「目前顯示：全部工作地點」）。

### 7.3 手機版佈局（Mobile $< 1024\text{px}$）：三頁式滑動切換體驗
針對手機直式螢幕寬度，將三欄重組為三個可左右平滑滑動（CSS Scroll Snap）的全寬頁面，並在頂部配置分段指示器（Segmented Tabs）：
* **頁 1（資源清單頁）**：上下整合「單位人員抽屜」與「搜尋框 + 主責單位地點抽屜」，頂部常駐明顯的「**清除選取**」按鈕。
* **頁 2（排程行事曆頁）**：支援月曆與單日清單切換，適合單手查閱每日排班。
* **頁 3（Web GIS 地圖頁）**：全螢幕地圖與圖層切換器，方便外業人員查看位置與一鍵導航。
* **動態浮動引導箭頭（Floating Directional Hints）**：
  * **情境一（在頁 1 點選人員或地點後）**：系統不強制跳轉畫面，而是在螢幕右側邊緣浮現帶有呼吸光暈的動態膠囊按鈕（如 `查看排程 →`），提示使用者已產生聯動結果，可向左滑動或直接點擊前往「頁 2」。
  * **情境二（進入頁 2 後）**：螢幕左側邊緣與右側邊緣分別顯示半透明浮動導引箭頭（`← 清單` 與 `地圖 →`），讓使用者直覺感知左右皆有連動頁面可滑動切換；進入「頁 3」後則在左側顯示 `← 行事曆` 浮動箭頭。
